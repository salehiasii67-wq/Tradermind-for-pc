# TraderMind OS

یک ژورنال معاملاتی آفلاین و پیشرفته برای تریدرها — ساخته شده با React + Electron.

## ویژگی‌ها

- 📊 ژورنال کامل معاملات با آمار و تحلیل
- 📈 داشبورد پیشرفته آنالیتیکس
- 🔒 کاملاً آفلاین — داده‌ها فقط روی دستگاه شما
- 🌙 حالت شب (Dark Mode) به صورت پیش‌فرض
- 🇮🇷 رابط فارسی با پشتیبانی کامل RTL
- 🖥️ اپلیکیشن دسکتاپ ویندوز (Electron)

## نصب

فایل نصب‌کننده `.exe` را از [Releases](../../releases) دانلود کنید.

## ساخت از سورس

### پیش‌نیازها

- Node.js 18+
- pnpm 9+

### دستورات

```bash
# نصب وابستگی‌ها
pnpm install

# اجرای وب (مرورگر)
pnpm --filter @workspace/tradermind run dev

# ساخت فایل exe ویندوز
cd artifacts/tradermind
pnpm electron:build
```

فایل نصب‌کننده در پوشه `artifacts/tradermind/dist-electron/` ساخته می‌شود.

## تکنولوژی

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, shadcn/ui
- **Database**: Dexie v4 (IndexedDB) — آفلاین و محلی
- **Desktop**: Electron 43
- **Charts**: Recharts
